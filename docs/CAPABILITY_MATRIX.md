# Capability matrix

| Capability | Available behavior |
| --- | --- |
| XML and ZIP | Preview, cancel, confirm, atomic import and repeatable reimport |
| Quantity observations | Catalog-based trends, documented units and source policies |
| Category or unknown records | Paginated source inspection, with sleep-specific analysis for known categories |
| Sleep | Daily union of reported asleep intervals and unambiguous stage totals |
| Workouts | Weekly duration, activity mix, latest sessions, and reported quantities |
| Activity rings | Exported daily summaries and goals |
| Explorer | Date and source filters, three granularities, comparison, distribution, raw inspection and aggregate CSV |
| Location routes, ECG attachments, FHIR, native HealthKit | Outside the supported import format |

See [implementation status](IMPLEMENTATION_STATUS.md) for limitations and verification.
